# Licenses and attribution

## Built during the hackathon
All code, configs, data generators, experiments, docs, diagrams and UI in this repository were written during the Meta Global AI Developer Hackathon, starting Oct 27, 2026. The git history records this. The project is released under the [MIT License](LICENSE).

## Data
All data is **synthetic and fictional**, generated by my own code (`src/anubhav/data/`, `configs/world_v1.yaml`):
- companies, people, sites, vehicles, registration numbers, orders, driver notes and operating rules;
- town names are real places in Telangana, used only as geography, with approximate distances.

No third-party dataset is included or redistributed. No real customer data is used. A logistics professional who gave background in an interview is not named, and the interview is not included.

## Research and examples I built on
Reimplemented in my own code; nothing copied.
- **Harness²**, Google Research, "Harness^2: Recursive Agent Harnessing for an Open World", [arXiv 2610.14224](https://arxiv.org/abs/2610.14224) (code: google-research/harness2, Apache-2.0). My tool-use loop (`src/anubhav/harness/`) adopts its Propose–Probe–Compose idea in a bounded form. I make no claim to that research.
- **Meta legal-agent-workshop** (`meta-models/legal-agent-workshop`), reviewed on 2026-10-30. Patterns I adopted: client timeout and retries, a run that stops cleanly when the model call fails, and a code check of the reply's claims.
