# EXP-018: does learning get better with more history? (scaling check)

**Verdict: met** (all three bars, all 9 runs complete). Frozen before any model call: `artifacts/benchmark/exp018_frozen.json` (plan sha `ecbbe0c19ec45fad`, script `2e0a37268cdd593e`).

**Setup.** Demo world (`full_seed20261104`), company T01. Muse Spark 1.3 on the Meta API mines the records as of day 30, 60 and 90 (cut at the end of 2026-08-30, 2026-09-29, 2026-10-29; "today" is the next day), 3 repeats each, every run into an empty store. The evidence gate checks against the same cut records. Scored with `evaluate.score` as in EXP-008/009b. At 90 days this is the live path: the only record left out is one phone-number staff edit dated 10-30, which the digest ignores.

**What changed with more history.** The Parkal Tuesday closure (H-16, weekly off) has no evidence in the first 30 days; it is found in every 60- and 90-day run. Nothing else changed: the same 8 rules at 30 days (Lakshmi Agencies 22 ft, 3 nicknames, Kazipet closure, V13's real capacity, Sri Durga at month end, the night-only site) are found in every run at every length.

**Missed at every length:** the nickname "Chowrasta load" (H-04) and the moved godown (H-17). Neither was ever proposed by the miner, so the gate never saw them. H-17 has no evidence by day 30.

**Caveats.**
- The 3 repeats gave the same rules each time (temperature 0), so they show stability, not spread.
- The miner proposed no trap rule in any run (0 traps proposed, so 0 rejected). B3 shows the pipeline did not admit one, not that the gate was tested against traps here. What the gate rejected were two non-matching habits (a receiving-hours cutoff; a vendor at month end).
- Read against the rules with evidence, recall is a little *higher* at 30 days (8/9) than at 60–90 (9/11): more history adds a learnable rule that is found (H-16) and one that is not (H-17).
- One company, one generated world; the hidden rules come from our own generator.
- Recall of 82% stops rising after 60 days; more days did not reach the two missed rules.
