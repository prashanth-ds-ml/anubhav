# Re-brief a teammate once

Use this when `delegate` returns `stop` other than `answered`, a `note` saying the answer may be partial, or an answer
that does not cover the brief.

1. **Read what came back.** Which part of the brief is answered, which is missing, and why it stopped (budget, a refused
   tool, a missing table or value).
2. **Re-brief once**, only if a narrower brief can work: name the missing part only, give the exact dates and values,
   and say what was already found so it is not repeated.
3. **Do not re-brief a second time.** If the second answer is still partial, stop.
4. **Tell the person plainly** what was found, what was not checked, and why. Never fill a gap with a guess.
