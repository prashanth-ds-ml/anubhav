## Short description (~50 words)
Anubhav is an AI agent for small logistics companies. It learns their unwritten rules from their own trip records. Meta Muse proposes each rule, code checks the evidence, and a person approves it. On an unseen test world, plans for unwritten rules went from 48% to 90% correct, with zero unsafe drafts.

## Long description (~300 words)
A dispatcher near Warangal knows that a 32 ft truck can't get into one godown in Jangaon. No system knows this. It lives in a driver's note and in the dispatcher's head. An AI agent connected to the company's data passes every check and still sends the 32 ft truck.

Anubhav fixes this with the company's own records. A dispatcher asks in Telugu, Roman Telugu or English, by text or voice. The agent plans a draft trip with 27 generic tools over the company's data. It never dispatches anything.

Behind the agent, Muse Spark 1.3 reads the trip history and proposes rules nobody wrote down. An evidence gate, written in code, checks each one. It needs supporting trips, rejects contradictions, and rejects habits that only look like rules. A person then approves each lesson as advice or as an enforced rule. The next plan uses it, and code checks enforced rules again before a draft is saved. Lessons can expire, be challenged and be rolled back.

Approved regional knowledge can be shared with a new company. Only regional facts travel, rewritten in the new company's ids, with a leak check. The new company opts in and can revoke.

When no tool fits, the agent can write a read-only SQL query in a sandbox. A query it keeps needing can become a new tool, but only after code checks it and a person approves it.

Every experiment was pre-registered, and its files were frozen by hash before any model call. On a world the system had never seen, lessons took unwritten-rule cases from 48% to 90% correct on Muse Spark Open, and from 45% to 90% on Muse Spark 1.3. A new company went from 33% to 100% on day 1. Both results held in 3 of 3 repeats. The failures are published too. All data is synthetic.

## Results, with honest limits
**What worked (pre-registered, files frozen by hash before any model call):**
- **Lessons beat searching raw notes.** On unwritten rules (gates, site nicknames, real truck capacity): 48% → 90% correct on Muse Spark Open (EXP-011R), and 45% → 90% on Muse Spark 1.3 (EXP-015). 0 unsafe drafts with lessons. Replicated in 3 of 3 repeats on both models.
- **Sharing works.** A new company went from 33% → 100% on its regional cases on day 1, with 0 leaks found by our leak check. Replicated in 3 of 3 repeats on both models.
- **The team as learning is added (EXP-014, Muse Spark 1.3, unseen world, one repeat).** The whole team went from 58.6% → 91.4% correct stage by stage, and unsafe drafts from 4 → 0. 3 of 5 pre-registered rules were met.

**What didn't work:**
- **EXP-014, tools:** no tool was made, so that rule was not met.
- **EXP-014, agent changes:** not met. Tool Forge's change passed its paired test and was approved, then scored 100% → 50% on its own questions. The last stage (91.4%) was below the one before (93.1%).
- **EXP-013:** the team is not more accurate than one Planner (47/54 against 48/54). It adds visible hand-offs and per-agent learning, not better answers.
- **EXP-016:** Muse Spark 1.3 made no learned tools. Learned tools were made and used only on Muse Spark Open (EXP-012b, 14 of 16 questions), and even there the cost bar was missed.
- **Real truck capacity** did not improve on either model.

**Limits:**
- **All data is synthetic,** made by our own generator, and the test cases come from the same generator. No real dispatcher has checked the lessons yet.
- Samples are small (20 cases behind the lessons result, 9 behind the sharing result, 3 repeats). EXP-013 and EXP-014 are one repeat each.
- Mining misses about 3 in 10 hidden rules, and every lesson still needs a person.
- The leak check is our own token check, not a formal privacy guarantee.

All 19 experiments, with their verdicts, failures included: `docs/trackers/experiments.md` and the app's Proof tab.
